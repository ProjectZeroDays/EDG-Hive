# 22 — Diagnostics and self-healing

**Goal:** The app can check and repair itself.

**Steps**
1. Sidebar troubleshooting button running self-diagnostics.
2. Safe automatic fixes, each reversible.
3. Testing and debugging agents that catch regressions and patch them.

**Done when**
- Diagnostics identify a seeded fault; the fix resolves it; rollback works.

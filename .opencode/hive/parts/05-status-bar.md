# 05 — Status bar

**Goal:** Connection state always visible.

**Steps**
1. Active green, reconnecting yellow, error/404 red.
2. Public IP, VPN and proxy state independently, grey when unset.
3. VPN and HTTP/HTTPS proxy toggles.

**Done when**
- Each state reproducible and labelled for screen readers.
